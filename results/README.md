# results/

Results archives (`results/<exp>/rep*-load*.zip`) are **not committed** — they are
reproducible from manifests + digests + the recorded environment metadata (§13). Only the
small derived summaries (`*-summary.md`, `*-summary.csv`) may be committed when a campaign
is frozen for publication, together with the manifest checksum they came from.

Analysis reads archives only (experiment-methodology skill): if a figure can't be
regenerated by `python3 notebooks/analyze_*.py results/<exp>`, it doesn't exist.
